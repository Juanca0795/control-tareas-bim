# UI/UX Pro Max para Control BIM

Skill oficial del proyecto [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) (licencia MIT), instalada en el repositorio para asistentes compatibles con la convención `.agents/skills`, como Codex.

**Uso inmediato desde la raíz de este repositorio:**

```powershell
python .agents/skills/ui-ux-pro-max/scripts/search.py "dashboard KPI dark minimal" --domain style
python .agents/skills/ui-ux-pro-max/scripts/search.py "chart comparison performance target" --domain chart
python .agents/skills/ui-ux-pro-max/scripts/search.py "compact dashboard" --stack html-tailwind
```

Se incluyeron catálogos de estilos, colores, producto, gráficos, tipografía, iconos, movimiento, UX, razonamiento y la guía HTML; las consultas especializadas para otros frameworks requerirían instalar sus respectivos archivos de stack.

Las reglas particulares para conservar la interfaz y lógica de Control BIM están documentadas en `design-system/control-bim/MASTER.md`. Esto **no instala una skill en ChatGPT ni en tu computadora Windows**: es una instalación versionada dentro del proyecto GitHub.
